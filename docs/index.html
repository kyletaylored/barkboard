BARKBOARD

A Datadog assistant showing live monitors, incidents, on-call, and SLOs on a 2.8″ touchscreen sitting on your desk.

What you'll need
  • An ESP32-2432S028R "CYD" board and a data cable
  • A Datadog org with an API Key and an Application Key
After flashing
  1. Join the open BarkBoard-XXXX WiFi network it broadcasts
  2. Pick your home WiFi in the captive portal
  3. Open barkboard.local and enter your API & Application keys
  4. It rotates through Overview, Monitors, Incidents, On-Call, and SLOs
