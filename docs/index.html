BarkBoard

Flash your Cheap Yellow Display
into a Datadog dashboard.

BarkBoard turns a $10 ESP32-2432S028R "CYD" touchscreen board into a always-on Datadog dashboard — monitors, incidents, on-call, and SLOs, glanceable from across the room. It's modeled on justynroberts/pagerduty-cyd, reworked to talk to the Datadog API instead of PagerDuty's.

Connect & flash

Plug in the board with a USB-C cable, click the button, pick the serial port.

Before you click flash

    
    
      
  • Desktop Chrome or Edge (WebSerial requirement — no Firefox, no Safari, no mobile)
    • 
      
  • A USB-C cable that actually carries data, not just power
    • 
      
  • The ESP32-2432S028R v2 "CYD" board — nothing to hold, no jumpers, no boot buttons, just plug in and click
    • 
      
  • A Datadog org (a trial works) with an API Key and a scoped Application Key — see step-by-step setup below
    • 
    

  


  

    
What happens after flashing

    
    
      
  1. 1The board reboots and broadcasts an open WiFi network named BarkBoard-XXXX (last 4 hex digits of its MAC). No password — join it from your phone or laptop.
    2. 
      
  2. 2A captive portal opens automatically (or visit http://192.168.4.1) — pick your home WiFi network and enter its password.
    3. 
      
  3. 3The board joins your network and drops its own AP. Open http://barkboard.local (or the IP address shown on the panel) to reach the setup page.
    4. 
      
  4. 4Enter your Datadog API Key and Application Key — no site/region field. BarkBoard probes the known Datadog sites automatically and stores whichever one validates.
    5. 
      
  5. 5Once validated, the device starts polling and rotates through its dashboard screens: Overview, Monitors, Incidents, On-Call, and SLOs.
    6. 
    

  


  

    
Datadog key setup

    

      In Organization Settings → API Keys, create/copy an API Key.
      In Organization Settings → Application Keys, create an
      Application Key scoped with read access to:
    

    
    
      
  • Monitors
    • 
      
  • Incidents
    • 
      
  • On-Call
    • 
      
  • SLOs
    • 
      
  • Hosts
    • 
    

    

      Scope names in the Datadog UI can shift over time — double-check the
      current list when you create the key.
    

  


  

    
Hardware gotchas worth knowing up front

    
    
      
  • This board's panel needs ILI9341_2_DRIVER, not ST7789_DRIVER — the firmware already has this right, just flagging it in case you're comparing against older CYD writeups.
    • 
      
  • The panel is dim and color-shifts noticeably off-axis. Straight-on viewing looks best; don't judge contrast from an angle.
    • 
      
  • If the screen stays solid white after flashing, it's almost always a USB cable that's power-only — swap it before assuming the flash failed.
